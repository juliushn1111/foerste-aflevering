University projects

Different problems.
A shared practical approach.

These projects were developed in groups during my studies at VIA.

Semester 01 · Group project

A game about plastic pollution

We developed a JavaScript computer game to raise awareness of plastic pollution. The project explored how an environmental issue could become an interactive experience.

JavaScript · Game development

Semester 02 · Group project

Elevator design & prototyping

We developed an elevator project using CAD drawings and 3D printing. Alongside the physical design, we used market and PESTEL analysis to explore its business context.

CAD · 3D printing · Market analysis · PESTEL

Semester 03 · Group project

A daily overview for kindergarten staff

We developed a Java application to help substitute staff find their way through daily routines. It brought together information about allergies, weather and activities to support planning the day.

Java · UML · Use cases · User stories

Semester 04 · Group project

Termonet & heating cost optimisation

We explored a Termonet system for a Danish area without district heating. Our client-server application supported different operating modes and provided an overview of energy consumption and costs, with a focus on price optimisation.

Java · Client-server systems · Domain modelling · UML
